# 💌 我们的小宇宙 —— 情人节情书网站

这是一个纯静态的网页小项目，用原生 **HTML + CSS + JavaScript** 写成，
没有使用 React / Vue，也没有数据库或后端服务。
手机打开效果最佳，电脑打开也会自动适配成宽屏布局。

打开 `index.html` 就能直接看，不需要安装任何东西、不需要联网。

---

## 📁 文件结构

```
love-letter/
├─ index.html          ← 网页主文件（结构）
├─ style.css           ← 样式文件（颜色、字体、手机/电脑布局）
├─ script.js           ← 交互逻辑（打字机效果、时间线动画、音乐播放、倒计时）
├─ README.md           ← 就是你现在看的这份说明
└─ assets/
   ├─ images/          ← 放你们俩的合照
   │   ├─ photo1.jpg … photo6.jpg   （按时间线顺序命名，名字可以在 script.js 里改）
   └─ music/            ← 放你们的专属背景音乐
       └─ our-song.mp3
```

## ✏️ 如何替换「文字」（你们的名字、情书内容、每一段回忆的文案）

打开 `script.js`，最上面有一大段写着

```js
const CONFIG = {
  ...
};
```

这是整个网站**唯一需要改的地方**，改这里网页就会自动更新，不用碰 HTML/CSS。

- `girlName`：她的名字（会显示在开头和结尾）
- `myName`：你的名字（会显示在落款处）
- `anniversaryDate`：纪念日日期，用于页面上的「倒计时 / 在一起多少天」
  - 格式必须是 `"YYYY-MM-DDTHH:mm:ss"`，例如 `"2023-02-14T00:00:00"`
- `timeline`：时间线数组，每一条是一段回忆，格式是：
  ```js
  {
    date: "2023.02.14",       // 显示的日期文字，随便写
    title: "第一次见面",       // 小标题
    desc: "那天下着小雨……",    // 具体回忆文字，可以写很长
    img: "assets/images/photo1.jpg" // 对应的照片路径，没有照片也没关系，会自动显示占位爱心
  }
  ```
  想增加/减少回忆，直接在数组里增加/删除一整段 `{ ... }` 即可。
- `letterParagraphs`：情书正文，是一个数组，每一项是一段话，会按顺序一段段地用打字机效果显示出来。
- `endingTitle` / `endingText`：结尾彩蛋页的标题和文字。

全部修改完，保存文件，刷新浏览器就能看到效果。

## 🖼️ 如何替换「照片」

1. 把你们的照片改名成 `photo1.jpg`、`photo2.jpg`……（也支持 `.png` / `.webp`，
   只要和 `script.js` 里 `img` 字段写的文件名、后缀对应上即可）。
2. 把文件复制进 `assets/images/` 文件夹。
3. 建议每张照片宽度不超过 1200px、大小控制在 500KB 以内，网页加载会更快
   （用手机自带的"编辑-压缩"或任意压缩图片的小工具都可以）。
4. 如果某一条回忆暂时没有照片，不用填 `img` 字段，网页会自动显示一个好看的爱心占位图，
   不会报错、也不会显示"图片裂开"的样子。

## 🎵 如何替换「背景音乐」

1. 准备一个 `mp3` 格式的音乐文件（体积建议 5MB 以内，加载更快）。
2. 把它改名为 `our-song.mp3`，放进 `assets/music/` 文件夹，直接覆盖替换即可。
3. 如果你想用别的文件名，打开 `index.html`，找到这一行：
   ```html
   <source src="assets/music/our-song.mp3" type="audio/mpeg" />
   ```
   把 `our-song.mp3` 改成你的文件名就行。
4. 因为手机浏览器规定"不能自动播放声音"，所以网页会有一个音乐播放/暂停按钮（🎵图标），
   需要她自己点一下才会开始播放，这是浏览器的安全规则，不是网页有问题。
5. 如果没有放音乐文件，播放按钮会自动隐藏，页面照常使用，不会报错。

## 📅 如何修改「纪念日 / 在一起天数」

还是在 `script.js` 的 `CONFIG` 里，改这一行：

```js
anniversaryDate: "2023-02-14T00:00:00",
```

改成你们真正在一起的那个日期（或者第一次见面的日期），
页面上「我们已经在一起 ___ 天」会自动根据这个日期和今天的日期算出来，不用手动算。

## 📱 关于手机 / 电脑显示

- 默认按手机竖屏设计（最常见的分享场景），字号、间距都已经调整过。
- 用电脑浏览器打开时，页面会自动变成居中的卡片式宽屏布局，不会出现页面被拉得很宽、
  字又很小的情况。
- 不依赖任何需要联网下载的字体或图标库，所以在没有网络、或者对方手机网速很差的时候，
  页面依然能正常打开、正常看到样式（只有音乐和照片本身需要本地文件存在）。

## 🚀 怎么发给她看

- **最简单**：把整个 `love-letter` 文件夹（连同 `assets`）压缩成一个 zip 发给她，
  解压后双击 `index.html` 用手机/电脑浏览器打开。
- **更有仪式感**：把文件夹上传到任意免费的静态网页托管服务（比如 GitHub Pages、
  Vercel、Netlify 等），生成一个网址链接发给她，点开就能看，不用下载任何文件。
