# 💌 我们的小宇宙 —— 情人节情书网站

纯静态网页，用原生 **HTML + CSS + JavaScript** 写成（参考了一个常见的"七夕/情人节电子情书"网站风格重新设计），
没有用 React / Vue，也没有数据库或后端。手机打开效果最佳，电脑打开会自动适配成宽屏布局。

打开 `index.html` 就能直接看，不需要安装任何东西、不需要联网。

---

## 📁 文件结构

```
love-letter/
├─ index.html          ← 网页主文件（结构）
├─ style.css           ← 样式文件
├─ script.js           ← 交互逻辑（唯一需要改内容的地方，见下文 CONFIG）
├─ README.md           ← 本说明文件
└─ assets/
   ├─ images/
   │   ├─ cover.jpg          ← "相恋计时"区的大图
   │   ├─ moment.jpg         ← "大图引言区"的背景图
   │   ├─ photo1~4.jpg       ← 时间线每条回忆配图
   │   └─ gallery1~6.jpg     ← 照片墙的 6 张照片
   └─ music/
      └─ our-song.mp3       ← 背景音乐
```

网页现在一共有这些板块（从上到下）：
封面开场 → 相恋计时 + 今日心语 → 引言过渡 → 我们的故事（时间线）→ 大图引言 →
照片墙 → 喜欢你的理由 → 两个人的计划（可勾选的心愿清单）→ 情书正文 → 结尾互动卡片 → 结尾彩蛋。

## ✏️ 如何替换「文字」

打开 `script.js`，最上面有一大段写着 `const CONFIG = { ... };`，
这是**唯一需要改的地方**，改这里网页就会自动更新，不用碰 HTML/CSS。各部分说明：

| CONFIG 字段 | 作用 |
| --- | --- |
| `girlName` / `myName` | 她的名字 / 你的名字 |
| `anniversaryDate` | 纪念日，格式 `"YYYY-MM-DDTHH:mm:ss"`，例如 `"2023-02-14T00:00:00"` |
| `hero` | 封面的小标签、副标题、大标题两行文字 |
| `counter` | 相恋计时区的图片路径和"今日心语"文案 |
| `quoteBreak` | 时间线前面那一整屏深色大字 |
| `timeline` | 回忆时间线数组，每条是 `{date, title, desc, img}`，增删一条回忆就增删数组里的一整段 |
| `photoQuote` | 时间线后面的大图引言（图片 + 一句话） |
| `gallery` | 照片墙数组，每张是 `{img, date, title}` |
| `reasons` | 喜欢你的理由，数组里每一项是一句话，会自动编号 |
| `bucketList` | 两个人的计划/心愿清单，每条是 `{icon, title, desc, done}`，emoji 随便换 |
| `letterParagraphs` | 情书正文，数组里每一项是一段话，按顺序打字机显示 |
| `final` | 结尾互动卡片的提问、按钮文字、点击后展开的告白文字 |
| `endingText` | 最后一屏的结尾文案 |

全部修改完，保存文件，刷新浏览器就能看到效果。

## 🖼️ 如何替换「照片」

1. 把照片放进 `assets/images/` 文件夹，按下表命名（也支持 `.png` / `.webp`，
   只要后缀和 `CONFIG` 里 `img` 字段写的一致即可）：
   - `cover.jpg`：相恋计时区的大图
   - `moment.jpg`：大图引言区背景
   - `photo1.jpg` ~ `photo4.jpg`：时间线每条回忆
   - `gallery1.jpg` ~ `gallery6.jpg`：照片墙
2. 建议每张照片宽度不超过 1200px、大小控制在 500KB 以内，加载更快。
3. 某张照片暂时没有也没关系：网页会自动显示好看的渐变占位图，不会报错、不会"裂图"。

---

## 🎵 如何替换「背景音乐」

1. 准备一个 `mp3` 格式的音乐（建议 5MB 以内），改名为 `our-song.mp3`，放进 `assets/music/` 覆盖替换即可。
2. 想用别的文件名：打开 `index.html`，找到 `<source src="assets/music/our-song.mp3" .../>` 这一行，把文件名改掉。
3. 手机浏览器规定"不能自动播放声音"，所以需要她自己点一下左上角的音乐按钮（🎵）或点"好呀，我们说定了"按钮才会开始播放，这是浏览器的安全规则。
4. 没有放音乐文件时，左上角的音乐按钮和提示文字会自动隐藏，不影响正常使用。

## ✍️ 关于「情书正文」的手写字体

情书正文（打字机效果那一段）默认使用**系统自带的手写风格字体**（比如 iPhone/Mac 上的"华文行楷"、
不少安卓机和电脑上的"楷体"），不用联网、不用装任何东西，打开就有手写感。

如果你想要更逼真、独一无二的手写效果，可以这样做：
1. 找一款**可免费商用、授权清晰**的中文手写字体（网上搜"免费商用手写字体"能找到不少，比如一些
   设计网站提供的"思源""站酷"系列手写字体，注意看清楚授权范围）。
2. 把字体文件转换/导出成 `.woff2` 格式，改名为 `handwriting.woff2`。
3. 放进 `assets/fonts/` 文件夹（这个文件夹现在应该已经有一个说明 txt，放进去的时候不用删它）。
4. 刷新网页，情书正文会自动换成这款字体；没放字体文件时，会自动使用上面说的系统字体，不会报错、
   也不会出现"方块字"。

## 📅 如何修改「纪念日 / 在一起天数」

在 `script.js` 的 `CONFIG` 里改这一行：

```js
anniversaryDate: "2023-02-14T00:00:00",
```

页面上"我们已经相爱 ___ 天 ___ 小时"会自动根据这个日期和当前时间算出来，不用手动算。

## ✅ 关于"两个人的计划"心愿清单

这个板块可以点击打勾，勾选状态会保存在**打开这个网页的这台设备、这个浏览器**里
（用的是浏览器自带的本地存储，不联网、不需要账号），下次用同一台设备、同一个浏览器打开时还会记得勾选状态。
如果想清空重来，清除一下浏览器的网站数据，或者换一个浏览器打开即可。

---

## 📱 关于手机 / 电脑显示

- 默认按手机竖屏设计，字号、间距、按钮大小（≥44px）都已经针对触摸操作调整过。
- 电脑浏览器打开时，时间线会变成左右交替排布，照片墙、理由卡片、心愿清单会变成多列网格，整体更有设计感。
- 不依赖任何需要联网下载的字体或图标库，没有网络、或者对方手机网速很差时页面依然能正常打开（只有照片和音乐本身需要本地文件存在）。

---

## 🚀 怎么发给她看

- **最简单**：把整个 `love-letter` 文件夹（连同 `assets`）压缩成一个 zip 发给她，解压后双击 `index.html` 打开。
- **更有仪式感**：把文件夹上传到 GitHub Pages / Vercel / Netlify 等免费静态网页托管服务，生成一个网址发给她，点开就能看。
