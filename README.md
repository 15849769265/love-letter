# 新新和慧慧的二人世界｜复刻源码

这是基于上传的网页与资源制作的本地静态网站，保留了故事时间线、照片墙、愿望清单、情书和最终约定画面，并把网站标题与人物称呼改为“新新和慧慧的二人世界”。

## 本地预览

1. 解压 ZIP。
2. 双击 `index.html` 即可打开；如浏览器限制本地音频或资源，建议在该目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000/`。

## 目录结构

- `index.html`：网页入口与文案。
- `assets/site.css`：原站主要样式。
- `assets/custom.css`：复刻补充样式、结尾约定画面。
- `assets/app.js`：恋爱计时、相册、愿望清单与背景音乐交互。
- `images/`：10 张本地照片。
- `audio/`：默认背景音乐目录。

## 背景音乐

当前提供的网页/资源压缩包中没有找到实际音频文件，所以无法把音频二进制打进这次 ZIP。音乐播放器已调整为：页面打开时尝试自动播放；若浏览器禁止自动播放，会提示点击音符；若未找到音乐文件，点击音符可直接选择你本机的 MP3、M4A、WAV 等文件播放。

若要让音乐随网站一起打包，先把音频复制到 `audio/` 文件夹，并命名为 `我们俩.mp3`，确保路径为 `audio/我们俩.mp3`。浏览器出于自动播放策略，仍可能要求用户点击一次播放按钮，无法由网页代码绕过这一限制。
